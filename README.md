## In development: Autonomous Microfactory OS

A production-style factory robotics software platform focused on the engineering problems behind large-scale automated systems:

- Python orchestration + Rust robot runtime
- Multi-robot traffic management and deadlock avoidance
- OR-Tools scheduling and resource allocation
- OpenCV / PyTorch / ONNX inspection pipeline
- PostgreSQL state persistence
- OpenTelemetry traces + ClickHouse event history
- Deterministic simulation, fault injection, and event replay
- Automated evaluation of recovery and diagnostic behaviour

The implementation is being built milestone-by-milestone with explicit simulation / integration / hardware-validation boundaries.
